## What it does

Reports findings with interpretation: orient, point to displays, compare, acknowledge problems, and note implications.

It treats results as needing words, because the same number can read as large or small depending on framing.

## When to reach for it

- **Invocation.** Model-invoked: the agent reaches for it when the task fits, or you can name it.
- **Trigger boundary.** Reach for this whenever numbers, tables, or figures need describing. For wording about meaning, see [evaluative-language](./evaluative-language.md).

## Common questions

**Won't evaluative wording look biased?**
Only if it is not anchored. Frame each number against a stated benchmark and use one scale throughout.

**Should I describe every result?**
No. Detail a few key, typical, or interesting ones; equal detail makes everything look equally important.

## It's working if

- The section opens with an overview or a look back, not a bare value.
- An important or unexpected result starts a new paragraph with an early signal.
