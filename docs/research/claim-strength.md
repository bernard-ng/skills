## What it does

Calibrates certainty to evidence at three levels (observation, interpretation, generalisation) and keeps it consistent across sections.

Hedging is calibration, not evasion.

## When to reach for it

- **Invocation.** Model-invoked: the agent reaches for it when the task fits, or you can name it.
- **Trigger boundary.** Reach for this on conclusions, abstracts, and "stronger" or "safer" rewrite requests.

## Common questions

**Should an abstract hedge?**
Plainly state supported findings; use "may" only if the paper also qualifies it.

## It's working if

- Claims match across Abstract, Results, Discussion, and Title.
