## What it does

Gives numbers their meaning: pick a benchmark, frame the number against it, match intensity to the size of the difference, and keep the scale consistent.

Framing must be defensible; it never persuades against the data.

## When to reach for it

- **Invocation.** Model-invoked: the agent reaches for it when the task fits, or you can name it.
- **Trigger boundary.** Reach for this when numbers appear without interpretation or tone is flat or inflated.

## Common questions

**Isn't plain description more objective?**
It reports the value but often adds nothing the reader cannot see in the figure, and readers may form a different opinion.

## It's working if

- The same effect size gets the same wording everywhere.
