## What it does

Weighs a pattern's problem, forces, and consequences against a plain alternative, then adapts it to local roles and records the decision.

It treats a pattern as a way to distribute duties, not a solution to adopt wholesale.

## When to reach for it

- **Invocation.** Model-invoked: the agent reaches for it when the task fits, or you can name it.
- **Trigger boundary.** Reach for this when a recurring problem matches a known pattern or a pattern is named in a request.

## Common questions

**Is using no pattern fine?**
Often it is the best answer. Name what the pattern would cost and what it would buy.

## It's working if

- You can say which problem it solves, what you gave up, and why a simpler option was not enough.
