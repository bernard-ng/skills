# Spatial description

Readers need to picture an apparatus well enough to rebuild it. Imprecise position words let them picture a different one.

## Procedure

1. Start from a diagram or the supplied layout. If neither exists, ask; do not guess geometry.
2. Fix the reference frame: relative to what, and from whose view? Name it (the inlet, the beam, the stage). "Left" and "right" need a viewing direction.
3. Choose the precise term for relation and closeness:
   - Contact and nearness: against, flush with, in contact with, next to, adjacent to, close to, within range of.
   - Vertical: above, below, directly above, just above, on top of, beneath.
   - Alignment: parallel to, perpendicular to, coaxial with, aligned with, intersecting, converging.
   - Distribution: equally spaced, equidistant, on either side, on both sides, on each side.
   - Flow and direction: upstream, downstream, near end, far end, front, rear.
4. Choose the right connection verb: mounted on, fastened to, coupled to, connected to, embedded in, encased in, surrounded by, fitted with, attached to.
5. Give dimensions as units, with consistent phrasing: "20 cm wide", "with a width of 20 cm", "half the width of", "twice as long as".
6. Match the tense to the claim: present simple for the fixed design ("The lens is mounted 5 cm below the source"), past simple for what was done in this study ("The lens was mounted..."). Use [voice](../active-passive-voice/SKILL.md) to tell standard design from this study.
7. Tie the description to a labelled figure or table, and check each position phrase against it.

## Guardrails

Do not infer distances, orientations, or connections. A sentence with several position phrases can attach them wrongly; split it. See [modifier placement](../modifier-placement/SKILL.md).

## Check

Could two readers draw the same sketch from the text? Does every position phrase agree with the supplied figure?

**Illustrative example:** "The detector is mounted 10 cm downstream of the nozzle and aligned parallel to the flow direction."
