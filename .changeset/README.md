# Changesets

Releases are managed with [changesets](https://github.com/changesets/changesets). Do not edit `CHANGELOG.md` or the `version` fields by hand. See [.agents/releasing.md](../.agents/releasing.md).

Add a changeset with `npm run changeset` whenever a change should reach users: a new, renamed, or removed skill, or a behaviour change in an existing one.
